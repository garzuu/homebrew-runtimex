# Homebrew Tap for RuntimeX

This tap provides the `runtimex` cask.

## Install

```bash
brew tap garzuu/runtimex
brew install --cask runtimex
```

## Release flow

- DMG and SHA256 are published by the `RuntimeX` GitHub release workflow.
- Update `Casks/runtimex.rb` for each release with the new version, URL, and SHA256.
